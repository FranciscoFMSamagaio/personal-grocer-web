# Seu Super Amigo

Cria uma página web simples, de uma só página (one-page), para um negócio de entregas de compras de supermercado ao domicílio. O negócio funciona assim: o próprio dono faz as compras no supermercado e entrega em casa do cliente (sem stock próprio, é um serviço de "personal shopper" + entrega).

Secções da página:

Hero (topo)

Nome do negócio: [nome do negócio]

Frase curta a explicar o conceito: ex. "Fazemos as tuas compras de supermercado e entregamos-te em casa."

Botão de destaque a ligar diretamente para o WhatsApp (ver secção 4)

Quem somos

2-3 frases a explicar o serviço: como funciona (cliente envia lista, tu compras, entregas em casa), zona de entrega ([cidade/zona]), e o que torna o serviço diferente/de confiança.

Preços / Como funciona

Tabela ou lista simples com os valores:

Taxa de serviço/entrega: [valor]

Valor mínimo de compra (se aplicável): [valor]

Zona de entrega e eventuais custos extra por distância: [detalhes]

Nota curta: o valor das compras é pago à parte (reembolsado por transferência/na entrega, conforme o teu modelo)

Contacto (WhatsApp)

Botão grande "Contactar via WhatsApp" que abre diretamente uma conversa, usando um link do tipo:
https://wa.me/351XXXXXXXXX?text=Ol%C3%A1%2C%20gostava%20de%20fazer%20uma%20encomenda

(substituir XXXXXXXXX pelo teu número, com indicativo 351)

Estilo/design:

Simples, limpo, mobile-first (a maioria vai aceder pelo telemóvel)

Cores: [à tua escolha, ex. verde/laranja associado a frescos]

Sem necessidade de menu complexo — tudo numa scroll page só

Botão de WhatsApp sempre visível (fixo no fundo do ecrã em mobile, idealmente)

Não incluir:

Carrinho de compras ou checkout — o contacto é sempre feito manualmente via WhatsApp
